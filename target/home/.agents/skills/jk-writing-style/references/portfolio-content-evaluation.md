# Portfolio content evaluation

Use this loop for technical articles, case studies, talk descriptions, project
copy, and bios that represent Alberto publicly.

## Loop

1. Draft or receive the content.
2. Score every applicable criterion from 1 to 10.
3. Diagnose each score below 8. Name the exact weakness, the evidence for it,
   and what a passing version must accomplish.
4. Rewrite weak sections as coherent units. Do not splice isolated phrases into
   a weak structure.
5. Re-score and repeat until every applicable criterion reaches 8 or a missing
   fact blocks an honest improvement.
6. Pressure-test the final draft against a skeptical senior engineer, a
   distracted reader, and the intended evaluator or customer.

Do not expose scores or editorial scaffolding unless the user asks for them.

## Shared criteria

- The opening makes the subject and stakes concrete.
- Consequential choices include the reason, strongest alternative, and ruling
  constraint.
- Claims use exact tools, versions, measurements, dates, and sources where the
  input supports them.
- Failures and tradeoffs are evidence, not reputation management.
- Alberto's contribution is distinct from team work.
- Each paragraph advances the reader's understanding.
- The ending pays the opening's promise without a generic recap.

## Content-specific criteria

For an article, assess progressive disclosure, runnable examples, value for a
senior reader, and whether the conclusion answers the opening question.

For a case study, assess problem and constraint clarity, decision trail,
measurable outcomes, role clarity, and details only a participant would know.

For a talk description, assess audience, concrete takeaway, novelty, title,
length discipline, and whether it wins against another session in the same
slot.

For project copy, assess one-line clarity, differentiation, technical precision,
proof points, and whether the gist is visible in five seconds.

For a bio, assess identity, specificity, career arc, current focus, and whether
a new reader understands Alberto's value in ten seconds.

If a criterion cannot pass without an author-only fact, stop and ask for that
fact rather than filling the gap.
